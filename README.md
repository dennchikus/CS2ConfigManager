# 🎮 CS2 Config Manager

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/твой-ник/CS2ConfigManager/releases)

**Портативная утилита для резервного копирования и переноса конфигов Counter-Strike 2.**

Программа позволяет сохранять настройки графики, игрового процесса и автоэкзеков с разных Steam-аккаунтов в собственное хранилище на флешке и легко переносить их на другие аккаунты.

## ✨ Возможности

- 🔍 **Автоматический поиск** аккаунтов Steam с установленной CS2.
- 👤 **Определение никнейма** и загрузка аватарки профиля.
- 💾 **Портативное хранилище** — все сохранённые конфиги лежат рядом с программой (на флешке).
- 📂 **Гибкое копирование** — можно выбирать отдельные категории (графика, игровой процесс, автоэкзек).
- ⏪ **Безопасность** — при применении конфигов автоматически создаётся резервная копия (бэкап).
- 🕶️ **Тёмная тема** и интуитивно понятный интерфейс.

## 🚀 Установка и запуск

### Для пользователей (Windows)

1. Перейди в раздел [Releases](https://github.com/твой-ник/CS2ConfigManager/releases).
2. Скачай последний архив `CS2ConfigManager.zip`.
3. Распакуй архив в любую папку (например, на флешку).
4. Запусти `CS2ConfigManager.exe`.

### Для разработчиков (из исходников)

Убедись, что у тебя установлен [Python](https://www.python.org/) (версия 3.10 или выше).

**Способ 1: Через современный менеджер `uv` (рекомендуется)**

```bash
git clone https://github.com/твой-ник/CS2ConfigManager.git
cd CS2ConfigManager
uv sync
uv run main.py
```

**Способ 2: Через стандартный `pip` и `venv`**

```bash
git clone https://github.com/твой-ник/CS2ConfigManager.git
cd CS2ConfigManager
python -m venv .venv
# Активация venv на Windows:
.venv\Scripts\activate
# Установка зависимостей и запуск:
pip install -r requirements.txt
python main.py
```

## 📖 Как пользоваться

1. Нажми **«🔍 Найти аккаунты»** — программа покажет все профили, где есть конфиги CS2.
2. Выбери аккаунт в левом списке.
3. Поставь галочки на том, что хочешь сохранить (например, «Графика»).
4. Нажми **«💾 Сохранить в хранилище»** и введи имя профиля.
5. Чтобы перенести настройки на другой аккаунт: выбери его, выбери сохранённый профиль из списка справа и нажми **«📥 Применить к аккаунту»**.

## ⚠️ Примечание

- Программа **не** загружает конфиги в Steam Cloud — она работает с локальными файлами.
- После применения конфига игру нужно перезапустить.
- Правый клик по профилю в списке открывает меню удаления.
- Все действия записываются в `storage/log.txt` — если что-то пойдет не так, загляни туда.
